Internal lab services planned by this configuration:

The exercise is designed for Labtainer's isolated Docker network.  Use only the
synthetic data shipped with the lab.  The configuration package intentionally
contains configuration and Docker build files only; the Python exercise source
files are developed separately and must emit the exact event markers listed in
instr_config/results.config.

Expected student flow after source files are installed:
  1. Start mail_server.py on victim-pc.
  2. Start listener.py on attacker-srv.
  3. Start chatbot_server.py on support-bot.
  4. Run send_email.py on attacker-srv.
  5. Run read_mail.py then call_support.py on victim-pc.
  6. Follow the lab conversation and run callback_client.py on victim-pc.
  7. Use checkwork callback-phishing to view progress.

All names, account details and data in this lab must remain fictitious.
